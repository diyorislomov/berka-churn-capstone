# Models Directory

This directory stores trained model artifacts generated by `notebooks/03_experiments.ipynb`.

## Files Generated (NOT committed to git)

| File | Description |
|---|---|
| `best_model.joblib` | The best-performing model artifact (sklearn Pipeline + metadata) |

The `.joblib` files are excluded from version control via `.gitignore` because they can be large and are fully reproducible from the training notebook.

---

## Loading the Model

```python
from src.predict import load_model, predict_churn

# Load model
model, feature_cols = load_model()

# Predict for a new account
result = predict_churn({
    'trans_count': 48,
    'trans_freq_monthly': 4.0,
    'avg_balance': 15000.0,
    # ... other features
})

print(result['churn_probability'])    # e.g. 0.73
print(result['risk_tier'])            # 'High' / 'Medium' / 'Low'
print(result['recommended_action'])   # retention action text
```

---

## Model Artifact Structure

The `best_model.joblib` file contains a Python dict with:

```python
{
    'model':        <fitted sklearn Pipeline>,
    'feature_cols': [list of 24 feature column names],
    'model_label':  'xgb' | 'rf' | 'lr',
    'val_roc_auc':  float,
}
```

## Reproducing the Model

To reproduce `best_model.joblib` from scratch:

1. Place Berka `.asc` files in `data/raw/` (see `data/README.md`)
2. Run `notebooks/01_data_join_eda.ipynb`
3. Run `notebooks/02_feature_engineering.ipynb` (creates `data/feature_matrix.parquet`)
4. Run `notebooks/03_experiments.ipynb` (trains all models, saves best to `models/best_model.joblib`)

Or run the demo notebook (`demo.ipynb`) which loads the pre-saved model.
